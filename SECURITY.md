# Security policy

Only the latest release receives security fixes. Compatibility is restricted to the Container Manager version listed in the README.

This application has privileged access to the Docker socket and Synology cache. Use it on a trusted network, protect the password file, retain repair backups, and stop it when maintenance is complete. Public images contain application code, not deployment credentials or runtime backups.

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/kzerghost/container-cache-guard/security/advisories/new). Do not disclose exploit details, passwords, real container configuration files, or backups in public issues. If private reporting is unavailable, open an issue requesting a private reporting channel without including sensitive details.
